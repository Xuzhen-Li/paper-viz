规范摘要（中文）

新加的图一律用 house style；已有的图不重渲染，继续用旧版 theme_viz()。完整规则见 styles/style-contract.md。

画布单栏 89 mm（width = "single"），双栏 183 mm（width = "double"）。双栏每行 3 个面板（约 58 mm），单栏每行 2 个；面板间距水平约 3 mm、垂直约 2.5 mm，外边距 ≤1 mm。
字号（印刷尺寸）双栏 / 多面板：刻度 7 pt、轴标题 8 pt（7/8 pt）；面板字母 10 pt 粗体小写 a b c；任何文字 ≥6 pt。
单栏只放 1 个面板：全部 +2 pt，刻度 9 pt、轴标题 10 pt（9/10 pt），pv_save_house() 自动加。字号不随面板缩小。
轴标题常规字重，不加粗；写变量名和单位，单位用括号。
边框与刻度四边 0.5 pt 黑框，刻度 0.5 pt、长 1 mm、向外；无网格，无次刻度（对数轴除外）。
线与点主数据线 1.5 pt，强调 / 拟合线 2.0 pt，次要系列 0.8 pt，参考虚线 0.5 pt，误差棒 0.7 pt。点 shape 21 加黑描边（size = 2.3, stroke = 0.3）。置信带同色 alpha 0.2。
图例默认不画图例，系列名直接写在图里，文字颜色 = 数据颜色；必须用时放框内右上、无边框。统计量（R²、P、N）写在图内，与组同色。
字体Arial → Helvetica → Liberation Sans → DejaVu Sans；中文思源黑体 / Noto Sans CJK SC。全图一种字体。
导出cairo PDF（文字保留为文本）+ 600 dpi PNG + 1200 px 宽 preview.png。

用法

# R：在 figures/<category>/<slug>/ 里
source("../../../styles/r/theme_house.R")   # 会顺带加载 theme_viz.R
p <- ggplot(df, aes(x, y, colour = group)) +
  geom_line(linewidth = pv_house_lw("main")) +
  scale_colour_manual(values = unname(pv_palette("house", 3))) +
  theme_house()                               # 7/8 pt；需要图例时 theme_house(legend = "inside")
pv_save_house(p, "figure", width = "single", height_mm = 76)   # 单栏单面板自动 +2 pt → 9/10 pt

# Python
import sys
from pathlib import Path
sys.path.insert(0, str(Path(__file__).resolve().parents[3] / "styles" / "python"))
import house                                  # styles/python/house.py
house.apply_house_style()
fig, ax = house.house_figure("single", height_mm=76)
ax.plot(x, y, color=house.pv_palette("house")[0])
house.save_house(fig, "figure")               # PDF + 600 dpi PNG + preview.png

Style summary (English)

New figures use the house style. Existing figures are not re-rendered and keep the legacy theme_viz(). Full rules: styles/style-contract.md.

Canvas89 mm single column (width = "single"), 183 mm double column (width = "double"). Three panels per row on 183 mm (about 58 mm each), two on 89 mm; gaps about 3 mm across and 2.5 mm down; outer margin ≤1 mm.
Text (print size)Double column / multi-panel: 7 pt ticks, 8 pt axis titles (7/8 pt); 10 pt bold lowercase panel letters; nothing under 6 pt.
One panel on 89 mm: everything +2 pt, 9 pt ticks and 10 pt axis titles (9/10 pt); pv_save_house() adds it. Text does not shrink with the panel.
Axis titlesPlain weight, not bold; variable name and unit in parentheses.
Frame and ticksFour-sided 0.5 pt black frame; ticks 0.5 pt, 1 mm, outward; no grid, no minor ticks (except log axes).
Lines and pointsMain lines 1.5 pt, emphasis / fit 2.0 pt, minor series 0.8 pt, dashed reference 0.5 pt, error bars 0.7 pt. Points: shape 21 with a black outline (size = 2.3, stroke = 0.3). CI ribbons in the series colour, alpha 0.2.
LegendsNo legend by default: label series in the panel in the series colour. When one is unavoidable, top-right inside the frame, no box. Statistics (R², P, N) go inside the panel in the group colour.
FontArial → Helvetica → Liberation Sans → DejaVu Sans; Chinese: Source Han Sans / Noto Sans CJK SC. One font per figure.
Exportcairo PDF (text stays text) + 600 dpi PNG + 1200 px wide preview.png.
